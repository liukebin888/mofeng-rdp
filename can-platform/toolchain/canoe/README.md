# CANoe 12 基础工程配置说明

> 配套 M1 里程碑。搭建四协议通道配置、数据库导入与仿真节点。

## 1. 工程结构

```
toolchain/canoe/
├── BusTest.cfg                 # CANoe 配置主工程
├── Databases/
│   ├── *.dbc                   # CAN/CAN FD 通信数据库
│   ├── *.arxml                 # AUTOSAR 系统描述（可选）
│   └── *.ldf                   # LIN 描述文件
├── Nodes/                      # 仿真节点（CAPL）
│   └── *.can
└── Panel/                      # 手动测试面板（可选）
```

## 2. 四协议通道配置要点

| 协议 | 通道 | 波特率 | 采样点 | 终端电阻 | 备注 |
|------|------|--------|--------|----------|------|
| CAN 2.0 | CAN1 | 500 kbit/s | 80% | 120Ω | 经典帧 |
| CAN FD | CAN2 | 仲裁 500k / 数据 2M | 仲裁 80% / 数据 75% | 120Ω | BRS 使能 |
| CAN XL | CAN3 | 仲裁 500k / 数据 8M | SIC 模式 | 120Ω | 需 CANoe 19+ 支持 FAST |
| LIN | LIN1 | 19.2 kbit/s | — | 主节点 1kΩ | 需 LDF 调度表 |

> ⚠️ 配置前须完成「USB v1 硬件型号确认」与通道自检，记录终端电阻与采样点基线（见 `results/hardware-ledger.md`）。

## 3. 数据库导入

1. CAN/CAN FD：导入 `.dbc`（或 `.arxml`），绑定通道。
2. LIN：导入 `.ldf`，确认调度表与 NAD 配置。
3. 数据库缺失时，可先用手写 CAPL 报文（`output()`）打通链路，M1 冒烟不阻塞于数据库。

## 4. 冒烟前置检查清单

- [ ] 驱动安装完成，通道在 CANoe 中可见；
- [ ] 终端电阻正确（CAN/CAN FD/CAN XL 120Ω；LIN 主节点 1kΩ）；
- [ ] 采样点/波特率与 DUT 一致；
- [ ] 先跑「链路冒烟」：发一帧标准报文，确认 DUT/回环收到（避免接口卡驱动未加载导致全 FAIL）。

## 5. M1 落点

M1 只搭基础工程 + 四协议冒烟用例（★ 标注项）。M2 引入 VT System 故障注入与干扰盒（VN6501/VH6501）。
