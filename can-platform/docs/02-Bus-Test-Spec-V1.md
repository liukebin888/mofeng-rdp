# 总线测试规范 V1 — CAN / CAN FD / CAN XL / LIN 测试项框架

> 版本 V1 · 2026-11-03 ｜ 配套 M1 里程碑
> 说明：本规范定义**测试项分层 + 判据 + 优先级**框架，是 M2 一致性/符合性套件的设计基线。M1 仅落地每协议 1 条冒烟用例（★ 标注）。

## 1. 分层模型（四协议通用）

测试项按 OSI 分层组织，优先级 P0（安全/合规强制）> P1（一致性核心）> P2（健壮性/边界）：

| 层 | 简称 | 内容 | 典型测试项 |
|----|------|------|-----------|
| L1 物理层 | PHY | 电平、位定时、振铃、终端电阻 | 采样点、位时间、振铃、Bus-off 恢复 |
| L2 数据链路层 | DLL | 帧格式、仲裁、位填充、CRC、错误帧 | 帧格式、填充、CRC、仲裁、错误帧处理 |
| L3 传输层 | TP | 多帧传输（ISO-TP） | 单帧/首帧/连续帧、流控、超时 |
| L4 网络管理 | NM | 休眠/唤醒、网络管理报文 | 唤醒脉冲、睡眠命令、NM 时序 |
| L5 诊断 | DIAG | UDS 服务（ISO 14229） | 会话控制、读写 DID、安全访问 |
| L6 应用层 | APP | 信号语义、周期、DLC | 信号值、周期抖动、超时检测 |

## 6. 判据与优先级说明

- **判据来源**：ISO 11898（CAN/CAN FD）、ISO 11898-1（CAN XL）、ISO 17987（LIN）、ISO 14229（UDS）、ISO 15765-2（ISO-TP）。
- **P0**：安全相关、合规强制、影响上线，M2 必须 100% 覆盖；**P1**：一致性核心，M2 覆盖 ≥80%；**P2**：健壮性/边界，M3 覆盖。
- **回退验证纪律**：每条测试项须「先注入已知违规样本，断言 FAIL → 再放行正确样本，断言 PASS」，杜绝零缺陷假阳性（与 mofeng-rdp 门禁同源）。
