# 四协议冒烟用例（M1 交付）

> 用途：打通「上位机 → USB v1 → 总线 → DUT」链路，验证四协议收发 + 采样点 + 位定时 + 报告输出闭环。
> 每条用例含：目的 / 前置 / 步骤 / 判据 / 回退验证。对应测试规范 V1 的 ★ 标注项。

## 冒烟用例清单

| 用例 ID | 协议 | 对应规范项 | 目的 |
|---------|------|-----------|------|
| SMOKE-CAN-01 | CAN 2.0 | CAN-01 标准帧收发 | 验证经典 CAN 周期报文收发一致 |
| SMOKE-CANFD-01 | CAN FD | CFD-01 FD 帧收发 | 验证数据域高速切换（BRS）收发 |
| SMOKE-CANXL-01 | CAN XL | CXL-01 XL 帧收发 | 验证 SIC 模式 XL 帧收发 |
| SMOKE-LIN-01 | LIN | LIN-01 帧头/响应收发 | 验证主从帧头/响应收发 |

---

## SMOKE-CAN-01 经典 CAN 标准帧收发

- **目的**：验证 CAN 2.0 标准帧（11 位 ID）周期报文按 DBC 定义正确收发。
- **前置**：USB v1 通道自检通过；终端电阻 120Ω；波特率 500k；采样点 80%。
- **步骤**：
  1. 按 DBC 定义发送周期报文（如 `EngineData`，周期 10ms）；
  2. 监听总线，校验 ID / DLC / 信号值；
  3. 连续收 10 帧，统计丢失率与周期抖动。
- **判据**：10 帧全部收到，ID/DLC/信号值一致，周期抖动 ≤ ±10%。
- **回退验证**：注入错误 CRC（或改 DLC）→ 断言触发错误帧/校验失败；恢复 → 断言 PASS。

## SMOKE-CANFD-01 CAN FD 帧收发

- **目的**：验证 CAN FD 数据域波特率切换（BRS 使能）后帧正确收发。
- **前置**：仲裁域 500k / 数据域 2M；BRS 使能；采样点仲裁 80% / 数据 75%。
- **步骤**：
  1. 发送 FD 帧（DLC=64，BRS=1）；
  2. 校验数据域 64 字节正确、切换位语义；
  3. 切换回经典 CAN 帧，确认兼容。
- **判据**：FD 帧数据域正确；与经典 CAN 共存无冲突。
- **回退验证**：BRS 位错 → 断言失败；恢复 → PASS。

## SMOKE-CANXL-01 CAN XL 帧收发（SIC 模式）

- **目的**：验证 CAN XL SIC 模式帧收发。
- **前置**：CANoe 支持 XL SIC（CANoe 19+）；仲裁域 500k / 数据域 8M。
- **步骤**：
  1. 发送 XL 帧（大 DLC，如 2048 字节）；
  2. 校验数据域长度与内容；
  3. 校验错误信号禁用（Error Signalling deactivated）。
- **判据**：XL 帧数据域正确；SIC 电平一致。
- **回退验证**：DLC 编码错 → 断言失败；恢复 → PASS。
- **⚠ 依赖**：若 USB v1/CANoe 12 不支持 FAST（PWM），M1 仅覆盖 SIC 模式，FAST 留待 M2 升级 CANoe 19。

## SMOKE-LIN-01 LIN 帧头/响应收发

- **目的**：验证主节点发送帧头、从节点正确响应。
- **前置**：LDF 导入；主节点 1kΩ 终端；波特率 19.2k；NAD 与 LDF 一致。
- **步骤**：
  1. 主节点按调度表发送帧头；
  2. 从节点（DUT）响应数据；
  3. 校验校验和（Classic/Enhanced）。
- **判据**：帧头触发响应，数据与校验和正确。
- **回退验证**：NAD 不匹配 → 断言无响应失败；恢复 → PASS。
- **⚠ 注意**：冒烟前先用 LIN Diagnostic 面板手动验证 NAD 与链路，避免接口卡驱动未加载导致全 FAIL。

## 冒烟执行与归档

1. 每次跑套件前先跑「链路冒烟」单帧，确认通信链路正常。
2. 保留原始 Trace，命名 `日期_固件版本_测试类型`（如 `20261103_v1.0.0_smoke-can`）。
3. 结果填入 `results/` 目录，并回填硬件台账（`results/hardware-ledger.md`）。
