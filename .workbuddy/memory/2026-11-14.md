### 关键教训
- **seed 数据改动必须升级 SEED_VERSION**，否则 localStorage 旧数据（version 匹配）直接加载，新 seed 不生效。这是既有的「seed 版本升级是合法迁移」铁律。
- **dev server HMR 不重载 seed 数据模块**，改 seed 后必须重启 dev server + 清 localStorage（或升级版本号）才能看到新数据。
