## P2 语义断层发现与修复（继续推进，用户拍板）
- **关键发现（比探针覆盖 C2 更严重）**：后端 `advanceStage` 前置判定只用 `gateReleaseEvidence`（只看审批实例 status=已完成），漏了「闸门通过」条件；而前端 `advanceStageVerdict` 用 `prerequisitesFullyReleased`→`stageFullyReleased`（审批+闸门都要）。导致「前置审批已完成但闸门未过」时后端错误放行（fail-open），违反 P2「只有批准（审批完成+闸门通过）才能实施下一阶段」，且探针会报不一致。
- 根因：advanceStage 前置循环 `ev.released()==true`（审批完成）直接跳过闸门检查；同服务的 releaseStage 却正确用 stageFullyReleased（审批+闸门），advance 与 release 语义不一致。
