## 交付物倒排结果回写 WBS + 导出 Excel 交付物日历

### 需求
把交付物倒排日历结果回写到项目计划（生成 WBS 交付物节点），并导出为 Excel 交付物日历。

### 用户裁决（3 项）
1. **回写挂载方式**：按质量门分组节点（8 个质量门为父节点，交付物挂到对应门下）。
2. **导出格式**：真 .xlsx 文件（引入 SheetJS/xlsx 依赖，打破「零第三方依赖」约定——用户明确要 .xlsx）。
3. **回滚策略**：回写前快照，可一键回滚。

### 实现落点
- `app/src/domain/types.ts`：`WbsNode` 新增可选字段 `dueDate?: string`（绝对完成日期 YYYY-MM-DD，向后兼容）。
- `app/src/domain/deliverableWbs.ts`（新建，单一权威）：
  - `buildDeliverableWbs(summary, projectId, projectStart?)`：把 `scheduleAllDeliverables` 结果按 8 质量门分组生成 WbsNode[]。门父节点 level=2/isMilestone/gate，叶子 level=3/parentId 指向门/dueDate。只生成有倒排日期的叶子（fail-closed，锚点缺失/无法解析/无要求不生成）。
  - 日期对接：WBS 的 planStart/planFinish 是「相对天数」（CPM 据此排布），倒排是绝对日期；以 projectStart（或最早 dueDate）为第 0 天换算 planFinish，绝对日期保留到 dueDate 字段。
  - `wireDependencies`：门父节点按 CG 顺序 FS 串联 + 门内叶子按 dueDate 升序 FS 串联，使 CPM 甘特能按倒排时序排布。
  - `mergeDeliverableWbs`（幂等去重，按稳定 id）、`removeDeliverableWbs`（回滚用）、`snapshotWbs`（深拷贝快照）、`wbsWriteAudit`（回写增量审计）。
  - 节点 id 稳定：门 `wb-gate-{CG}`，叶子 `wb-{CG}-{seq}-{idx}`；code 前缀 `WB-`（与既有 WBS 编码隔离）。
- `app/src/utils/exportXlsx.ts`（新建）：`exportXlsx(fileName, sheets)`，基于 SheetJS 社区版，多 Sheet + 每 Sheet 首部带口径元数据行（FUN-019）。
- `app/src/views/flow/ApqpFlowView.vue`：第④ tab 新增「回写 WBS / 回滚 / 导出 Excel」三按钮 + 回写审计展示。回写走 `store.saveWbs`，回写前 `snapshotWbs(store.projectWbs)` 快照，回滚还原快照。导出生成 3 Sheet：交付物日历（10 列明细）/质量门汇总/待治理清单（锚点缺失+无法解析）。
- `app/src/views/plan/WbsView.vue`：任务明细表新增「完成日期」列（展示 dueDate，空显示 —）。
- `app/tests/deliverableWbs.spec.ts`（新建，13 测试）：质量门分组/叶子挂载/fail-closed/幂等合并/保留既有节点/快照深拷贝/移除回滚/审计/天数换算/基准日默认/依赖链。

### 关键决策与注意
- WBS 的日期语义是「相对天数」（CPM es/ef 从 0 推，忽略 planStart/planFinish），故回写须把绝对日期换算为相对天数 + 用 dueDate 字段保留绝对日期。

- `buildWbs()` seed 返回空数组（去演示化），回写后 WBS 仅含交付物节点，无预置演示数据。
