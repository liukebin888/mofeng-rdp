## 11. 补全判据（设计者纪律）

1. 每个引擎以本表「验收要点」为唯一判据，逐条实现 + 单测。
2. 先写**已知违规样本回退测试**，再实现，最后跑六门禁。
3. 探针披露「请求数 / total>0 数 / 内容变化数」，杜绝零缺陷假阳性。
4. 数据变更快照 + 回滚；只读/导出零业务写入。
5. 禁止「引擎存在即视为达成」——必须可复算、可验证、有单测。
