## 0. 设计者立场（本计划的纲）

本工具是**汽车零部件研发项目管理平台**。作为设计者，我承担三项不可外包的职责：

1. **定义产品**：什么该先做、什么该砍、做到什么深度，由我凭 APQP/PPAP/16949/等保专业判断。
2. **定义边界**：规模（1 万用户 / 5000 并发 / 年 3000 项目）、技术栈、合规底线，由我给出明确结论。
3. **定义验收**：每一项「做到什么算达标」，由我定可测量的判据，做完提交验证给结论。

需求方只做两件事：**范围/商务边界确认**、**验收结论**。

## 1. 规模与合规约束（设计硬指标）

| 约束 | 数值 | 设计含义 |
|---|---|---|
| 用户规模 | ≥ 10,000 人 | RBAC 分级、18 角色矩阵、多租户隔离必须真实可用，非演示 |
| 并发在线 | 5,000 人 | 需连接池 + 缓存 + 索引 + 异步任务，单进程 JSON 文件存储不可行 |
| 数据规模 | 年 3,000 项目 | 需关系型数据库 + 分区 + 归档策略 + 追溯闭包表 |
| 合规 | 等保三级 + 密评 + 国密 | 需国密网关 + 证据链台账 + 真实测评结论 |

## 2. 技术路线（设计者结论）

**结论：按 SRS 锁定的 Java 栈交付，领域规则复用当前纯函数引擎作为「规则权威表达」。**

理由（基于规模约束的严肃判断）：

| 判断项 | 结论 |
|---|---|
| 5000 并发 + 年 3000 项目 | 单进程 Node 零依赖 + JSON 文件存储**无法满足**，需 MySQL 8 分区/索引 + 连接池 + 缓存 |
| 等保三级 + 国密 | Java/Spring 生态（BouncyCastle 国密、Spring Security、成熟网关）是合规最短路径 |
| 当前 63 个纯函数引擎 | **不可丢弃**——它是业务规则（分级判定真值表、CPM 正逆推、48 控制点、追溯闭包、基线哈希链、合规证据链）的**权威可复算实现**，已验证 640 例。这些规则语言无关，可完整迁移到 Java 领域层 |

**演进策略（非推倒重来）**：

```
当前（Node + 纯函数引擎 + 56 视图）  ← 已完成的「规则权威表达 + 需求验证」
        │
        │ 继续机制层完善（本计划主线）：把纯函数引擎作为规则唯一来源，补全 SRS 覆盖
        ▼
Java/Spring 应用层 + 基础设施层     ← 按 SRS 锁定栈，承载 5000 并发 + 等保 + 国密
        │
        │ 领域层规则从 TS 引擎迁移（1:1 语义对齐，用同一套 640 例测试作为迁移验收基线）
        ▼
R1 可试点版本（真实数据库 + 真实测评 + 真实集成）
```

**关键纪律**：TS 纯函数引擎在整个过渡期始终是「业务规则的唯一权威」。Java 领域层以「通过同一套测试用例」为迁移完成的判据，禁止出现两套规则各说各话。

## 3. 阶段路线图（战略）

### 阶段 A：机制层收口（当前 → R1 机制层 100% 覆盖）

**目标**：把 SRS 515 条中「可在纯函数层表达的规则」全部实现为 domain 引擎 + 单测，让规则权威完整无缺口。

**完成判据**：
- SRS R1 批次 226 条中，凡属「规则/判定/约束」性质的条目，100% 有对应纯函数引擎 + 单测
- 六门禁全绿：vue-tsc 0 err、vitest 全过、build、smoke、e2e、隔离面
- 每新增引擎必须**先过已知违规样本的回退验证**（杜绝零缺陷假阳性）

### 阶段 B：企业级基础设施落地（规模约束兑现）

**目标**：把「1 万用户 / 5000 并发 / 年 3000 项目」从纸面变成可验证能力。

**关键项**：
- MySQL 8 数据层（替代 JSON 文件存储）：分区、索引、追溯闭包表、归档策略
- Redis 缓存 + 会话 + 限流
- ES 检索（如 R2 需要，R1 可延后）
- 国密网关（SM2/SM3/SM4）+ 传输加密落地
- 等保三级 / 密评：系统做完整 → 提交测评 → 给结论（验证后置）

### 阶段 C：R1 可试点版本闭环

**目标**：交付一个「能真实试点、能通过验收」的 R1 版本（220 条范围）。

**完成判据**：
- 功能模拟测试跑通（几项目 + 相关人员全流程）
- 等保/密评测评结论「符合」
- 性能压测达 5000 并发、年 3000 项目数据量不劣化

### 阶段 D：R2/R3 批次交付

**目标**：R2（试点后补齐）、R3（推广优化），按批次里程碑推进。
