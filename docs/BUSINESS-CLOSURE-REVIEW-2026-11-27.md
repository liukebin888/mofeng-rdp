## 三、系统性评估

**结论：✅ 体系收敛，主轴清晰**

18 个一级菜单组围绕「审批驱动阶段门禁」主轴，形成了完整的分层：

```
工作中心 ──┬─ 项目前期(报价/TR/立项) ─ 项目管理(任务书/主计划/OTS/PPAP/SOP)

           ├─ AI 智能辅助 ─ 基础数据 ─ 行政管理 ─ 系统管理
```

**与上轮对比**：上轮「组合投资并入成本、交付并入采购」的语义错位已修复，两个 PMO/交付功能回归独立组，系统性恢复清晰。

## 八、整改建议（按优先级）

### P0（需产品定位确认）

1. **「会议决议→任务→督办」链条去向**：这是本轮唯一的 🔴 级断链。该链条在引擎层已完全移除（非仅菜单裁撤），需确认是产品定位调整（如 R1 明确不纳入协同会议模块）还是功能遗漏。若有意裁撤，需在 PRD/SRS 中明确登记并说明替代方案；若需保留，需恢复引擎 + 菜单。

### P1（一致性收敛）

2. **组合投资组 URL 改名**：`/cost/score`→`/portfolio/score`、`/cost/capacity`→`/portfolio/capacity`、`/cost/analysis`→`/portfolio/analysis`、`/cost/eps`→`/portfolio/eps`、`/cost/gate-consistency`→`/portfolio/gate-consistency`，消除组名与 URL 的不一致。

3. **交付管理组 URL 改名**：`/supply/deliverables`→`/delivery/deliverables`、`/supply/ship`→`/delivery/ship`、`/supply/soft`→`/delivery/soft`。

4. **router 注释同步**：`router/index.ts:26` 注释「16 个一级菜单」改为「18 个」（与 U5-D3 未决项合并处理）。

### P2（复用收敛）

5. **EvmView 四处复用拆分**：成本偏差/工时归集/四值挣值/供需超分配应加页内 Tab 或拆分组件，且避免同一组件分散在「成本管理」和「行政管理」两组。
