## 1. 产品目标

在既有 `/trial/inspect` 页面提供一张「样件评审模板」，把样件评审固化为「阶段一：评审小组逐项评审并给出评审结论 → 阶段二：将该评审结论提交审批（批准 / 驳回）」的两段式闭环，确保**评审结论先于审批产生、审批基于已形成的结论作出**。该模板须接入 WF-001 统一四按钮，且与现有单一权威判定同源、不产生第二套相互矛盾的结论口径。

## 2. 用户故事

1. As a **质量工程师（评审发起人）**，I want 基于空白评审模板「新增」一张样件评审单、填写评审项清单并可保存 / 关闭 / 提交，so that 发起行为符合 WF-001 统一四按钮规范，且新增时不带入任何已有数据。
2. As a **评审小组成员**，I want 在阶段一对样件逐项评审（评审项清单 + 逐项结论 / 意见）并汇总给出评审结论，so that 评审意见与结论在提交审批之前完整留痕、可追溯。
3. As a **评审小组组长 / 结论下达人**，I want 在评审项全部完成后下达评审结论、再「把该结论提交审批」，so that 审批人拿到的是**已形成的结论**而非待定事项（先结论、后审批）。
4. As a **审批人（角色待定）**，I want 在阶段二查看已提交的评审项清单与评审结论，作出批准 / 驳回并填写审批意见，so that 审批基于评审结论进行，驳回后可退回再评审。
5. As a **项目 / 质量管理人员**，I want 在 `/trial/inspect` 同一页面看到一张评审单「评审 → 审批」两阶段的当前状态与结果，so that 无需切换菜单即可追踪完整闭环、且页面上只存在一份权威结论口径。
