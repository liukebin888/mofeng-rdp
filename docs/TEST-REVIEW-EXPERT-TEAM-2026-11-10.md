## 六、阻断级问题（优先整改）

### B1｜probe 门禁崩溃（白樾/何序/闻朔共同确认）
- 现象：`seed.ts` 去演示化（`buildProjects()` 返回 `[]`）后，`probe-compute.mts:23-24` 仍硬编码 `PROJECT_ID='P-001'`，`find(...)!` 返回 undefined，`:38` `p.budget` 抛 TypeError。
- 影响：`npm run probe` 一致性探针门禁整体失效；smoke/e2e 已适配空态，唯探针漏改。
- 修改：空态下优雅降级或注入合成数据，删除 P-001 硬编码与非空断言。

### B2｜前端硬编码 JWT 密钥 + 客户端自签（关屿）
- 现象：`apiV1.ts:78` 硬编码 `DEV_JWT_SECRET`，`issueJwt()` 浏览器端签发任意身份；后端 `SecurityAutoConfiguration.java:27` 同密钥。Node 预签名密钥 `server/index.js:185` 硬编码回退。
- 影响：拿到前端包即可伪造任意身份越权。
- 修改：令牌仅后端签发，后端密钥缺失即拒绝启动（fail-closed）。

## 七、关键发现汇总（按域）

- **集成/契约/接口**：零真实集成/契约测试；apiV1.spec 为 mock 单测；两套后端契约并存（Node `{ok,...}` vs Java `{code,message,data}`），Node 接口无契约文档；`repo.ts:57-74` 乐观锁 409 信号丢失。
- **系统/验收**：85 条 AC 无验收闭环（条目库 xlsx 缺失）；BDD 零 .feature；e2e 断言退化为存在性检查。
- **测试保障**：回归无 CI 无版本化；探针链崩溃且不在 vitest 回归集内；冒烟被做成全路由扫描、断言弱、无失败隔离。
- **性能/可靠性**：零压测资产；`server/index.js` 单进程同步全量读写；无高可用/无限流熔断；`RateLimitEngine.isCoreBlockedByLoad()` 恒 false。
- **安全**：cipher.ts 自造 XOR 无 IV；interop.ts 伪 HMAC；Node 全端点无鉴权 + CORS `*`；审计哈希链未密钥化。
- **兼容/无障碍**：`accessibilityAudit` 硬编码假取证（恒报 100%）；浅色主题 `--text-3 #8593a8` 对比度 3.12:1 真实失败；99 个 .vue 无 ARIA；兼容矩阵缺失。
- **流程/度量/代码**：无 CI/lint/覆盖率/变异工具；文档数字全面失实（640/744 vs 1333 例，63/70 vs 109 引擎，79 vs 105 路由）；`store/app.ts` 3624 行 god object；`productCodeData.ts` 13196 行。
- **单元级缺口**：109 domain 引擎中 risk/kitting/masterPlanLanes 三核心引擎零直接单测；后端 infrastructure 模块 68 主文件零测试。
